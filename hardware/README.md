# Hardware

Design files for the physical system:

- `antennas/` – Vivaldi antenna notes, measured S11, custom PCB antenna designs
- `mounts/` – antenna head, absorber housing, frame (CAD / STL)
- `gantry/` – scanning rail / 2-axis gantry
- `pcb/` – controller and RF switch boards

Current antenna: 0.7–9 GHz antipodal Vivaldi (PCB). Measured on a NanoVNA-H: SWR ≈ 1.3–1.8 from
~0.8 to ~1.35 GHz, rising to ~2.4 at 1.5 GHz.
